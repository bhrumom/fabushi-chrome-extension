# 架构与实现策略

Reuse userscript-recovery.js as the single active-task lease source. Add Chrome power permission and a syncKeepAwake(records) helper. A valid non-expired recovery record implies requestKeepAwake("system"); otherwise releaseKeepAwake(). Call reconciliation after lease request/release, watchdog scans, tab removal, and service-worker startup. Do not use display keep-awake.
